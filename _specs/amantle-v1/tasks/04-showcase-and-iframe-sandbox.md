# 04: Витрина каталога и изолированное превью (Showcase & Iframe Sandbox)

**Статус:** todo

**Блокируется:** 01 (Ядро проекта), 03 (Компоненты «Золотого фонда»).

**Закрывает критерии:** К3, К5.

## Что построить

Полноценный интерактивный веб-интерфейс каталога компонентов:
- **Главная страница каталога (`app/(marketing)/page.tsx`)**:
  - Hero-секция платформы AMANTLE UI с возможностью быстрого поиска.
  - Табы переключения разделов: `UI Components`, `Blocks`, `Templates`.
  - Сетка карточек компонентов с мини-превью, тегами и кратким описанием.
  - Живой поиск и фильтрация по названию и тегам на клиенте.
- **Страница детального просмотра компонента (`app/(marketing)/[category]/[slug]/page.tsx`)**:
  - Изолированный Iframe-песочница с роутом `/preview/[category]/[slug]`, исключающий влияние стилей страницы документации на стили компонента.
  - Тулбар управления превью:
    - Переключение вьюпорта: Mobile (375px), Tablet (768px), Desktop (100%).
    - Переключение вариантов компонента.
    - Переключение темы внутри превью (синхронизировано с глобальной темой витрины).
  - Кнопка «Copy CLI» (`npx shadcn add https://amantle.dev/r/[slug].json`) с анимацией подтверждения (Checkmark / Sonner toast).
  - Кнопка «Copy Code» с копированием чистого TSX в буфер обмена.
  - Вкладка «Code» с подсветкой синтаксиса и вкладка «Installation» с перечнем зависимостей.
  - Карточка «Provenance & License» с указанием источника, автора и лицензии.

## Критерии приёмки

- [ ] В каталоге работает мгновенный поиск компонентов без перезагрузки страницы.
- [ ] Превью компонентов рендерится внутри изолированного iframe без утечки внешних стилей.
- [ ] Переключение размеров экрана (375px, 768px, 100%) плавно меняет ширину фрейма превью.
- [ ] Клик на «Copy CLI» копирует валидную команду `npx shadcn add` и выводит уведомление (toast).
- [ ] Клик на «Copy Code» копирует чистый код компонента без артефактов страницы документации.
- [ ] На странице каждого компонента отображается блок атрибуции Provenance (автор, источник, лицензия MIT).
