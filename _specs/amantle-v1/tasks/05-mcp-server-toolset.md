## Что построить

Полноценная интеграция AMANTLE UI в AI-стек через Model Context Protocol (MCP):
- MCP-сервер на базе `@modelcontextprotocol/sdk` (поддержка SSE/HTTP через роут `app/api/mcp/route.ts` и локального stdio запуска через скрипт `scripts/mcp-server.ts`).
- Реализация 4 инструментов (tools) с Zod-схемами параметров:
  1. `search_registry`: поиск компонентов по смысловым запросам, категориям и тегам. Возвращает краткие карточки совпадений.
  2. `get_component`: извлечение полного кода компонента, списка npm-пакетов и внутренних зависимостей реестра для прямой вставки в проект.
  3. `list_categories`: вывод дерева разделов и агрегированной статистики по доступным элементам.
  4. `get_theme_tokens`: генерация готового блока CSS-переменных для выбранной цветовой палитры и режима темы (dark/light) для настройки `globals.css` в проекте пользователя.
- Тестовый скрипт проверки вызова всех 4 инструментов.

## Критерии приёмки

- [x] MCP-сервер успешно инициализируется и регистрирует 4 инструмента (`search_registry`, `get_component`, `list_categories`, `get_theme_tokens`).

- [x] Инструмент `get_theme_tokens` возвращает валидные CSS-переменные для выбранной темы.
