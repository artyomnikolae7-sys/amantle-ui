## Что построить

Сквозной работающий фундамент веб-приложения AMANTLE UI:
- Базовая конфигурация проекта: `package.json`, TypeScript (`tsconfig.json`), Next.js 15 (App Router).
- Интеграция Tailwind CSS v4 с архитектурой токенов в `globals.css` на CSS-переменных.
- Провайдер темы оформления (`ThemeProvider`) с поддержкой светлого и тёмного режимов, а также 5 встроенных палитр (Zinc, Slate, Violet, Emerald, Rose).
- Базовый лейаут приложения (`app/layout.tsx`) с шапкой, навигацией и интерактивным переключателем тем.
- Успешный запуск локального dev-сервера командой `npm run dev` без ошибок и предупреждений в консоли браузера.

## Критерии приёмки

- [ ] Проект успешно запускается командой `npm run dev` на порту 3000 и корректно отображает стартовую страницу.
- [ ] В `globals.css` настроены CSS-переменные дизайн-системы для `:root` и `.dark` в соответствии с Tailwind v4.
- [ ] В интерфейсе шапки работает переключатель темы (Dark / Light) с сохранением выбора в `localStorage`.
- [ ] В интерфейсе шапки работает переключатель цветовых палитр (Zinc, Slate, Violet, Emerald, Rose), динамически меняющий акцентный цвет всех элементов интерфейса.
- [ ] Сборка `npm run build` и проверка типов `npm run lint` проходят без ошибок.
