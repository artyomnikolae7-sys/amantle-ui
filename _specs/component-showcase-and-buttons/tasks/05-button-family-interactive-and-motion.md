## Что построить

Пользователь получает набор из 5 премиальных интерактивных кнопок с микро-анимациями:
- `registry/ui/button-magnetic.tsx`: кнопка, мягко притягивающаяся к курсору при наведении с плавным возвратом.
- `registry/ui/button-ripple.tsx`: кнопка с материальным волновым ripple-эффектом из точки нажатия.
- `registry/ui/button-shimmer.tsx`: акцентная CTA-кнопка с анимированным бегущим лучом по границе (Border Beam) или световым бликом.
- `registry/ui/button-expandable.tsx`: кнопка с плавно выезжающей стрелкой/иконкой и расширением при ховере.
- `registry/ui/button-tilt.tsx`: карточная 3D-кнопка с пространственным наклоном по траектории движения мыши.

Все компоненты поддерживают `motion-reduce:` для доступности.
