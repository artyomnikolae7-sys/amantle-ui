# 03: Интерактивный таб Playground и синхронизация с вкладкой Code

**Статус:** done

**Блокируется:** 01-showcase-toolbar-and-viewports, 02-copy-for-ai-dropdown

**Закрывает критерии:** К4, К5

## Что построить

Пользователь видит третью вкладку «Playground» рядом с «Preview» и «Code»:
- Панель визуальных контролов для управления свойствами компонента (селектор варианта, селектор размера, переключатели состояния `disabled` и `loading`, поле ввода текста, селектор иконок).
- Компонент на холсте в реальном времени перерисовывается при изменении любого контрола.
- Вкладка «Code» динамически формирует и показывает JSX-сниппет использования именно с теми пропсами, которые выставлены в Playground.
- Кнопка `[🔄]` сбрасывает интерактивные пропсы к начальным значениям.

## Критерии приёмки

- [x] В `ShowcaseViewer` добавлена вкладка `Playground` в основной переключатель табов.
- [x] Реализованы интерактивные элементы управления пропсами: селекты (`variant`, `size`), свитчи (`loading`, `disabled`), текстовое поле (`label`), селектор иконок.
- [x] Изменение контролов мгновенно отображается на живом компоненте на холсте.
- [x] Вкладка `Code` динамически перегенерирует JSX-код вызова с актуальными пропсами и поддерживает переключение `Usage / Source`.
- [x] Кнопка `[🔄]` в тулбаре сбрасывает пропсы в исходные значения по умолчанию.
