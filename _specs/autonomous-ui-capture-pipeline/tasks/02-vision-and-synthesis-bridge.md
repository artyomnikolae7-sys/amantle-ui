## Что построить

Модуль синтеза и автоматической нормализации, интегрированный с `scripts/pipeline.mjs` и движком захвата `scripts/ui-capture-engine.mjs`. Модуль принимает профиль движения и исходный код (или кадры взаимодействия), генерирует выверенный React + Tailwind v4 код:
- внедряет CSS-переменные дизайн-системы (`bg-background`, `text-foreground`, `border-border`, `--radius`);
- заменяет неэффективные переходы на точные пружинные токены (`--spring-smooth`, `--spring-snappy`);
- добавляет обязательное физическое `:active` сжатие (`scale(0.97)`);
- добавляет директивы `motion-reduce:transition-none` и `motion-reduce:active:scale-100`;
- генерирует строгий JSDoc `@source`, `@author`, `@license`, `@modified`.

## Критерии приёмки

- [x] Реализована функция автоматической оптимизации движения `enhanceComponentMotion(code, profile)`.
- [x] Код валидируется на отсутствие `transition: all`.
- [x] Автоматически проставляются классы доступности `motion-reduce:*`.
- [x] Сохраняются все импорты и Radix/Slot паттерны.
