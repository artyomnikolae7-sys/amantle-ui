## Описание
1. Добавить метаданные новых компонентов в `public/r/index.json`.
2. Создать индивидуальные JSON-манифесты в `public/r/<name>.json`.
3. Зарегистрировать превью-рендереры в `lib/components-map.tsx`.
4. Запустить верификацию:
   - `npx.cmd tsc --noEmit`
   - `npm.cmd run test` (MCP юнит-тесты)
   - `node scripts/audit-routes.mjs` (проверка 100% HTTP 200 статуса маршрутов)
5. Провести многоосевое ревью кода:
   - Стандарты (`AGENTS.md`, `_docs/stack.md`)
   - Спецификация (`_specs/deep-research-ui-evolution/spec.md`)
   - Безопасность (XSS, sanitized DOM)

## Критерии приёмки
- 100% тестов проходят успешно.
- 0 ошибок TypeScript.
- Все маршруты отдают HTTP 200.
