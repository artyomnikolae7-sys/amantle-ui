## Что построить

Добавить в `components/showcase-viewer.tsx` функционал A/B сравнения:
1. Кнопка переключения `[⚖️ A/B Compare]` в верхнем тулбаре или табах.
2. В режиме A/B сравнения экран разделяется на:
   - **Вариант A (Референс / Оригинал)**: исходный код / превью до нормализации.
   - **Вариант B (AMANTLE UI Адаптация)**: живой интерактивный компонент на токенах дизайн-системы.
3. Интерактивная панель аудита токенов:
   - Список заменённых классов (например: `bg-zinc-900` → `bg-card`, `border-zinc-800` → `border-border`).
   - Оценка совместимости с дизайн-системой (100% Tokenized).
4. Поддержка переключения режима отображения: «Side-by-Side» (рядом) или «Split Overlay» (наложение со сплиттером).

## Критерии приёмки

- [x] В `ShowcaseViewer` добавлена кнопка/режим `[⚖️ A/B Compare]`.
- [x] Пользователь может просматривать Вариант A (исходный код и стиль) и Вариант B (адаптированный код и живой рендер).
- [x] Отображается карточка диффа заменённых токенов и метрики чистоты кода.
- [x] Переключение между режимами работает плавно без сброса состояния холста.
