## Что построить

Провести полный демонстрационный цикл 3-минутного онбординга нового интерактивного компонента:
1. Выбрать новый компонент (например, `badge-shimmer` или `input-floating-label` или `card-spotlight`).
2. Запустить единую команду:
   ```bash
   node scripts/pipeline.mjs --source <url-or-file> --name <name> --category ui
   ```
3. Проверить:
   - Анализ зависимостей и пропсов.
   - Адаптацию к токенам AMANTLE UI.
   - Появление компонента на сайте в Sidebar и Catalog.
   - Работу вкладки Playground с интерактивными контролами.
   - Работу режима A/B сравнения.
   - Успешное прохождение тестов роута и манифеста.

## Критерии приёмки

- [x] Новый компонент успешно добавлен через единую команду пайплайна.
- [x] Время выполнения пайплайна зафиксировано (< 10 сек машина, весь цикл ~3 мин).
- [x] Компонент доступен на сайте по адресу `/<category>/<name>`.
- [x] В `ShowcaseViewer` доступен режим A/B сравнения с отображением диффа токенов.
