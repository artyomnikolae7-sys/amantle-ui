# 04: Автоматическое Тестирование и Скриншот-Валидация

**Статус:** done

**Блокируется:** 01-pipeline-analyzer-and-normalizer, 02-automated-registration-and-playground

**Закрывает критерии:** К6, К7

## Что построить

Создать шаг автоматического тестирования в пайплайне:
1. Проверка синтаксиса TypeScript и валидности экспортов.
2. Проверка сборки манифеста `public/r/<name>.json`.
3. Запрос к роуту изолированного превью `/preview/<category>/<name>` и проверка кода HTTP 200.
4. Вычисление метрики скорости выполнения (бенчмарк: полный прогон пайплайна < 10 секунд).

## Критерии приёмки

- [x] В `scripts/pipeline.mjs` интегрирован модуль `verifyComponentRoute(name, category)`.
- [x] Модуль проверяет код ответа HTTP 200 роута превью.
- [x] Ошибки компиляции или битые импорты детектируются до добавления в индекс.
- [x] Полное время выполнения машинных шагов укладывается в 10 секунд.
