# Масштабирование AMANTLE UI до 100 Компонентов (100-Components Milestone)

## Постановка проблемы

Сейчас в дизайн-системе AMANTLE UI зарегистрировано 62 компонента (32 UI, 27 Blocks, 3 Templates). Для превращения платформы в полноценную экосистему уровня shadcn/ui требуется расширить коллекцию до **ровно 100 компонентов**, покрыв ключевые паттерны современного веб-дизайна (SaaS, дашборды, AI-интерфейсы, интерактивные карточки, формы и навигацию).

## Решение

Используя созданный 3-минутный конвейер `scripts/pipeline.mjs`, пакетно добавить и валидировать **38 новых компонентов**:
- **Пакет 1: UI Primitives & Interactive Compounds (+18 компонентов, итого 50 UI)**:
  1. `card-spotlight` — карточка со световым пятном, следующим за курсором
  2. `card-tilt` — карточка с 3D-наклоном при наведении
  3. `card-glass` — неоморфичная glassmorphism-карточка с матовым блюром
  4. `input-floating-label` — инпут с плавающей анимацией лейбла
  5. `input-otp` — ввод 6-значного OTP-кода подтверждения
  6. `input-search-animated` — поисковый инпут с шорткатом (Cmd+K)
  7. `kbd` — клавиатурный бейдж шорткатов
  8. `tabs-pill` — вкладки-пилюли с плавающим индикатором
  9. `tabs-vertical` — вертикальные вкладки для боковых меню настроек
  10. `badge-pulse` — бейдж статуса с анимированной пульсирующей точкой
  11. `avatar-group` — стек аватаров с наложением и бейджем количества
  12. `tooltip-animated` — всплывающая подсказка с плавной анимацией
  13. `stepper` — пошаговый визард этапов с индикатором прогресса
  14. `breadcrumbs` — навигационные хлебные крошки
  15. `scroll-area` — кастомный стилизованный скроллбар
  16. `rating` — интерактивный звёздный рейтинг с hover-эффектом
  17. `collapsible` — сворачиваемый блок с плавной анимацией высоты
  18. `toggle-group` — группа кнопок-тумблеров (Single/Multi выбор)

- **Пакет 2: Blocks для SaaS и Лендингов (+15 компонентов, итого 42 Blocks)**:
  19. `hero-split-image` — hero-блок с текстом слева и промо-изображением справа
  20. `hero-floating-mockup` — hero-блок с парящим 3D-мокапом интерфейса
  21. `pricing-toggle-annual` — тарифы с переключателем Месяц/Год (-20%)
  22. `pricing-slider` — интерактивный калькулятор тарифа с ползунком
  23. `feature-timeline` — вертикальный таймлайн развития продукта
  24. `feature-bento-spotlight` — бенто-сетка с эффектом слежения за мышью
  25. `feature-comparison-matrix` — таблица сравнения возможностей против конкурентов
  26. `testimonials-marquee` — бесконечная горизонтальная бегущая лента отзывов
  27. `testimonials-grid-masonry` — сетка отзывов с рейтингами и аватарами
  28. `faq-searchable` — аккордеон FAQ с живым поиском по вопросам
  29. `cta-split-card` — конверсионный баннер с инпутом email и соц. пруфом
  30. `footer-minimal-centered` — лаконичный центрированный футер
  31. `navbar-floating-glass` — парящий островной навбар со стеклянным блюром
  32. `dashboard-activity-feed` — лента активности пользователей с таймлайном
  33. `dashboard-quick-actions` — сетка быстрых действий для рабочей панели

- **Пакет 3: Templates (+5 компонентов, итого 8 Templates)**:
  34. `changelog-page` — страница истории версий и обновлений продукта
  35. `pricing-page-full` — развернутая страница цен с калькулятором, FAQ и CTA
  36. `settings-account-page` — экран настроек аккаунта с боковыми вкладками
  37. `error-404-page` — интерактивная страница ошибки 404 с возвратом домой
  38. `blog-post-template` — шаблон статьи блога с оглавлением и автором

## Критерии приёмки

- **К1**: Общее количество зарегистрированных компонентов в `public/r/index.json` достигло ровно 100.
- **К2**: Все 38 новых компонентов имеют семантические классы Tailwind CSS v4 (`bg-primary`, `bg-card`, `border-border`, `--radius`) и `source provenance` JSDoc.
- **К3**: Все компоненты зарегистрированы в `lib/components-map.tsx` и `lib/playground-schemas.ts`.
- **К4**: Команда `npm run build:registry` компилирует ровно 100 валидных JSON-манифестов в `public/r/`.
- **К5**: Все 100 изолированных роутов превью `/preview/<category>/<name>` возвращают HTTP 200 OK.
- **К6**: Тестовый набор MCP Tools (`npm test`) проходит 10/10 тестов без ошибок.
