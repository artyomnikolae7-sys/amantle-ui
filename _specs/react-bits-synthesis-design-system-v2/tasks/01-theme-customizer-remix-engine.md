# Таска 01: Дизайн-система Remix & Интерактивный кастомизатор тем (Theming Engine)

## Статус: COMPLETED

## Закрывает критерии: К1

## Блокировки: нет (стартовая таска)

## Описание
Реализовать полноценную систему кастомизации оформления в стиле shadcn/ui Remix:
1. Создать модуль состояния темы (`lib/theme-customizer.ts`):
   - Радиусы: `0` (brutal/sharp), `0.3rem` (compact), `0.5rem` (default), `0.75rem` (soft), `1.0rem` (curved), `9999px` (pill).
   - Палитры: `zinc`, `slate`, `stone`, `emerald`, `blue`, `violet`, `rose`, `amber`.
   - Режимы отображения (light / dark).
   - Сохранение в `localStorage`.
2. Создать компонент `components/theme-customizer-modal.tsx` (или панель в навигации):
   - Выпадающий или плавающий интерфейс с превью цветов, кнопками радиусов и быстрым сбросом.
   - Кнопка "Копировать CSS код токенов" в буфер обмена.
3. Добавить CSS-переменные палитр и радиусов в `app/globals.css`.
4. Интегрировать кастомизатор в шапку сайта `components/navbar.tsx` и превью страницы.
