# Таска 03: Глубокий синтез текстовых анимаций React Bits (Text Animations)

## Статус: COMPLETED

## Закрывает критерии: К3

## Блокировки: 02-component-families-hierarchical-sidebar.md

## Описание
1. Извлечь и портировать передовые компоненты текстовой анимации из React Bits:
   - `split-text`: разбивка по буквам/словам с каскадной пружинной задержкой (spring stagger).
   - `shiny-text`: переливающийся металлический/световой блик вдоль текста.
   - `blur-text`: постепенное проявление текста из расфокусировки с motion-blur.
   - `decrypted-text`: эффект дешифровки матричного / киберпанк текста с перебором символов.
   - `true-focus`: фокусировка на активном слове с анимированной рамкой видоискателя.
   - `rotating-text`: вертикальная замена слов с трехмерным вращением.
   - `gradient-text`: живой динамический градиентный поток на тексте.
   - `count-up`: плавный анимационный счетчик чисел с поддержкой форматирования.
2. Реализовать каждый компонент в `registry/ui/`:
   - React 19, TypeScript, Tailwind v4.
   - Пружины Emil Kowalski (`stiffness: 400`, `damping: 30`).
   - Поддержка `prefers-reduced-motion`.
   - Полные JSDoc заголовки `@source reactbits.dev`.
3. Зарегистрировать в `lib/components-map.tsx`, сгенерировать JSON-манифесты через `scripts/build-registry.mjs`.
