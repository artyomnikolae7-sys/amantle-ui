## Описание
1. Извлечь и портировать инновационные компоненты взаимодействия (исключая бэкграунды):
   - `click-spark`: искры и световые частицы при клике.
   - `star-border`: анимированная переливающаяся звездная окантовка вокруг кнопки или карточки.
   - `elastic-slider`: эластичный ползунок с физикой натяжения.
   - `pixel-card`: интерактивная карточка с пиксельным градиентным шлейфом при наведении.
   - `warm-tooltip`: тактильный тултип с мягким пружинным раскрытием и микро-стрелкой.
   - `jelly-radio`: радиокнопка с эффектом мягкого желе (jelly physics) при переключении.
   - `spring-check`: чекбокс с пружинной отрисовкой галочки и тактильной пульсацией.
   - `pill-nav`: плавающая навигационная панель с перемещающейся подсветкой активного элемента.
2. Реализовать компоненты в `registry/ui/` с чистым кодом без сторонних тяжелых библиотек (использовать нативный CSS transition/animation и SVG/Canvas).
3. Добавить в `lib/components-map.tsx`, обновить тесты и реестр.
